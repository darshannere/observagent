# Quick Task 260319-295: Fix Cost by Model Panel Showing No Data

## One-liner

Added `stmtCostByModel` prepared statement and extended GET /api/cost to return `models` array with aggregated cost data per model.

## What Was Done

The `/api/cost` endpoint previously returned `{sessions, todayTotal}` but the LiveDashboard's Cost by Model panel expected a `models` array with `{model, cost, sessions}` entries — which was always empty.

**Changes made to `routes/api.js`:**

1. **Added `stmtCostByModel` prepared statement** (after `stmtTodayCost`):
   ```sql
   SELECT model, SUM(total_cost_usd) AS cost, COUNT(DISTINCT session_id) AS sessions
   FROM session_cost WHERE agent_id = '' GROUP BY model
   ```

2. **Updated GET /api/cost handler** to query `stmtCostByModel` and include `models` in the response:
   ```javascript
   fastify.get('/api/cost', (request, reply) => {
     const sessions = stmtSessionCost.all();
     const todayRow = stmtTodayCost.get();
     const models = stmtCostByModel.all();
     reply.send({ sessions, todayTotal: todayRow.total, models });
   });
   ```
